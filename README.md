# steam_review_scraper
数据来源于官方API接口真实可靠，支持steam上的常用语言、数量、时间、steam直购筛选，并自动计算好评率、同时导出txt和CSV文件（有原链接可检查）
 
爬数据需要用加速器 加速steam，国区锁区游戏都可以爬，短时间内节点频繁爬取可能会被V社暂时禁爬，但你可以换其他节点，然后又可以继续爬了
 
steamcommunity 302 国区测试可以
锁区游戏通常需要大陆之外的地区，推荐日、美区节点
  
源代码是用Python编写，推荐python3.9以上
需要配置库如下：pip install requests pandas urllib3

双击打开steam_review_scraper.py运行即可
